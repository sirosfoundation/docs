# API Reference

import SwaggerUI from '@site/src/components/SwaggerUI';

This page provides interactive API documentation for the SIROS ID platform services. Each API specification can be explored below, and the raw OpenAPI/Swagger files are available for download.

## Go-Trust API {#go-trust}

The Go-Trust API is a multi-framework trust decision engine providing AuthZEN-based trust evaluation. It supports ETSI TS 119612 trusted lists, OpenID Federation, and DID Web trust frameworks.

- **Version:** 2.0
- **License:** BSD-2-Clause
- **Repository:** [sirosfoundation/go-trust](https://github.com/sirosfoundation/go-trust)
- **Spec:** [Download OpenAPI spec](/api/go-trust-swagger.yaml)

## Wallet Backend Admin API {#wallet-backend-admin}

Internal administration API for managing the wallet backend multi-tenant infrastructure. This API manages tenants, users, credential issuers, and verifiers.

- **License:** Apache 2.0
- **Repository:** [sirosfoundation/go-wallet-backend](https://github.com/sirosfoundation/go-wallet-backend)

## VC Platform APIs {#vc-platform}

The [VC platform](https://github.com/SUNET/vc) provides the core credential issuance and verification services for SIROS ID. It exposes several service-specific APIs:

### API Gateway (Datastore) {#vc-apigw}

The API Gateway (apigw) serves the OpenID4VCI/OAuth endpoints and the datastore REST API of the VC platform. The specification below covers the datastore operations only, not every apigw route. All paths in it already include the `/api/v1` prefix.

- **Version:** 2.8
- **Spec:** [Download Swagger spec](/api/vc-apigw-swagger.yaml)

### Registry (Token Status Lists) {#vc-registry}

The VC registry service is the Token Status List service: it serves `GET /statuslists` and `GET /statuslists/{id}`, plus an optional admin GUI under `/admin`. See [Token Status Lists](./token-status-lists). The Swagger specification published for it, [vc-registry-swagger.yaml](/api/vc-registry-swagger.yaml), currently defines no paths, so no interactive documentation is shown here.

### Issuer {#vc-issuer}

The VC issuer service is a gRPC service (`proto/v1-issuer.proto` in the [VC repository](https://github.com/SUNET/vc)); over HTTP it exposes only `/health` and `/swagger`. The Swagger specification published for it, [vc-issuer-swagger.yaml](/api/vc-issuer-swagger.yaml), currently defines no paths. See [API Integration](../issuers/api-integration#grpc-integration) for the gRPC interface.
